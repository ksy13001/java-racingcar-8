# java-racingcar-precourse
## 기능 구현 목록

- 입력(Input)
  - 자동차 이름 입력받기
  - 시도 횟수 입력받기

- 입력 분리(InputParser)
  - 쉼표(,) 기준으로 입력 분리
  - 각 토큰마다 공백 제거

- 입력 검증(InputValidator)
  - 이름
    - 이름 길이 범위 1~5
    - 이름이 공백일 경우 예외
    - 중복된 이름일 경우 예외
  - 시도횟수
    - 시도 횟수 범위 1~100(최대 시도횟수 100회로 가정)
  - 잘못된 입력은 IllegalArgumentException 발생시키고 프로그램 종료

- 자동차(Car)
  - 이름으로 생성
  - 이름 반환
  - 전진
  - 전진횟수 반환

- 랜덤값 생성(RandomValueGenerator)
  - 0 ~ 9 사이 무작위 값 생성

- 출력(Output)
  - 경주 라운드마다 자동차 이름과 전진 횟수 출력
  - 우승자 출력
  - 우승자가 여러명일 경우 쉼표(,)로 구분해서 출력

- 게임(Game)
  - 자동차 생성
  - 경주 진행
    - 시도 횟수만큼 라운드 반복 
    - 자동차 전진은 무작위 값이 4 이상인 경우 가능
  - 우승자 선정
